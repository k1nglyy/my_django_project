Документация пользователя
==========================

Страницы на сайте
----------------

На сайте присутствуют следующие страницы:

- Главная страница
- Страница времени
- Страница калькулятора
- Страница выражений
- Страница истории выражений
- Страница подсчета слов в строке
- Страница истории строк
- Страница входа
- Страница выхода
- Страница кликера

Страница калькулятора
---------------------

Чтобы вычислить сумму на странице калькулятора, необходимо:

1. Перейти на страницу калькулятора.
2. Передать два числа в качестве URL-параметров ``a`` и ``b``.
3. Сумма чисел будет отображена на странице.

Страница подсчета слов в строке
-------------------------------

Чтобы узнать количество слов в строке на соответствующей странице, необходимо:

1. Перейти на страницу подсчета слов в строке.
2. Ввести строку в поле ввода.
3. Отправить форму.
4. Количество слов и чисел в строке будет отображено.

Страница выражений
------------------

На странице выражений отображается случайно сгенерированное математическое выражение и его результат. Выражение сохраняется в истории.

Страница истории выражений
--------------------------

На странице истории выражений отображаются все ранее сгенерированные и сохраненные выражения вместе с их результатами.

Страница истории строк
----------------------

На странице истории строк отображаются все ранее введенные строки вместе с их анализом (количество слов и символов).

Страница кликера
----------------

На странице кликера можно изменять характеристики персонажа (HP, IQ, счастье).

Страница входа и выхода
-----------------------

На страницах входа и выхода пользователи могут авторизоваться и выйти из системы соответственно.
